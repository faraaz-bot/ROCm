# ROCm 8.0.0 Release

**Release Date**: March 18, 2026 (2026W16)  
**Branch Date**: February 26, 2026 (2026W9)  
**AMDGPU Driver**: 31.10.x

## Overview

**ROCm 8.0.0** is the first ROCm release recommended for production based on the new build system "The Rock". This is a major milestone in the ROCm platform evolution.

## Key Features

### New Build System "The Rock"
- First production-ready release using the new build system
- All packages are organized into:
  - **ROCm core**: Essential components
  - **ROCm expansion packs**: Market vertical-specific packages
  - **Misc pack**: Standalone projects

### New Capabilities
- **Offline runfile installer**: Simplified installation without internet connectivity
- Improved package organization and dependency management
- Enhanced build system reliability and performance

## Important Notes

```{important}
This release may also be referred to as ROCm 7.12 in some contexts during the transition period.
```
