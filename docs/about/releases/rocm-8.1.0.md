# ROCm 8.1.0 Release (RO W17)

**Release Date**: April 20, 2026 (2026W17)  
**Branch Date**: April 2, 2026 (2026W14)  
**AMDGPU Driver**: 31.20.x

## Overview

ROCm 8.1.0 is a significant release that provides Day 0 support for Ubuntu 26.04 LTS.

## Key Features

### Ubuntu 26.04 Day 0 Support
- Release package built specifically for Ubuntu 26.04
- Ensures compatibility with the latest Ubuntu LTS release from day one
- Optimized for the new Ubuntu platform

### Release Cadence Adjustment
- **Special Note**: This release deviates from the standard 6-week cycle
- Reduced by 1 week to align with Ubuntu 26.04 release schedule
- Demonstrates ROCm's commitment to supporting major platform releases

## Technical Details

- AMDGPU driver updated to 31.20.x series
- Full compatibility with Ubuntu 26.04 LTS
- Continued support for existing platforms
